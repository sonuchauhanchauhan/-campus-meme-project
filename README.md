# 📰 Campus Daily Meme News

An **AI-powered campus meme news website** that generates **viral Hinglish meme-style headlines** about students, just like an Instagram meme page.
Built with **Django + AI**, it creates funny, relatable campus headlines automatically.

---

## 🚀 Features

* 🤖 **AI Meme Generator** – Generates viral meme-style campus headlines
* 📰 **News Paper Style UI** – Looks like a real news website
* 🔥 **Breaking News Format** – Meme headlines appear like breaking campus news
* 😂 **Hinglish Meme Style** – Relatable jokes for Indian college students
* ⚡ **Auto Refresh Headlines** – New meme headlines appear automatically
* 🎯 **Random Student Pairing** – Different students get roasted each time

## ⚙️ Installation

Clone the repository:

```
git clone https://github.com/yourusername/campus-meme-news.git
```

Move into the project folder:

```
cd campus-meme-news
```

Create virtual environment:

```
python -m venv myenv
```

Activate environment:

```
myenv\Scripts\activate
```

Install dependencies:

```
pip install -r requirements.txt
```

Run migrations:

```
python manage.py migrate
```

Start server:

```
python manage.py runserver
```

Open in browser:

```
http://127.0.0.1:8000
```
